# EgyMart Admin Portal — Security Review Status

Reviewed against `EgyMart Admin Portal – Security Review.pdf` (32 findings: `C1–C3`, `H1–H9`, `M1–M11`, `L1–L9`) on 23 Nov 2026.

## Summary Matrix (All 32 Findings)

| ID | Severity | Finding | Status | Notes |
| --- | --- | --- | --- | --- |
| **C1** | Critical | Change password sent without a login token; target user chosen in URL | **Closed** *(already fixed)* | `AuthService.ChangePasswordAsync` uses `SignedClient` (JWT). API `RecoveryV2Controller.ChangePassword` enforces `[Authorize(Roles = "5")]` for admin resets; self-service `ReplaceOldPassword` requires `oldPassword` and checks caller identity. |
| **C2** | Critical | Request-signing key & fixed IV shipped to every browser | **Closed** *(this pass)* | Deleted `Handlers/SignatureHandler.cs`, removed `SignatureHandler` from `Program.cs`, and deleted `window.cryptoHelper` (and its hardcoded key) from `wwwroot/js/app.js`. API `[Signture]` filter is not applied to any controller. |
| **C3** | Critical | Tokens in refresh URL, JWT printed to console, refresh token never rotated | **Closed** *(already fixed)* | `AuthService.TryRefreshTokenAsync` POSTs `{ ExpiredToken, RefreshToken }` in JSON body, has no `Console.WriteLine`, and persists rotated `Jwt` + `RefreshToken`. |
| **H1** | High | Login enforced only in the browser | **Closed** *(this pass + API)* | `App.razor` gates `<Router>` behind `AuthService.HasValidSessionAsync()` before rendering pages. API `AdminDashboardV2Controller` tightened to `[Authorize(Roles = "3,4,5")]` and `SupplierV2Controller` to `[Authorize(Roles = "2,5")]`; all admin auth/CMS/product/ads/reporting endpoints enforce JWT + role checks. |
| **H2** | High | User identity taken from data the user controls (`sign`, `userData`, `verifiedID`) | **Closed** *(already fixed + C2)* | `SignatureHandler` removed. API `VerifyV2Controller` overwrites `verifiedID` from JWT `ClaimTypes.NameIdentifier`. |
| **H3** | High | Signature doesn't cover method/query/body; replayable | **Closed** *(this pass)* | Removed `SignatureHandler` and `window.cryptoHelper` (see C2). |
| **H4** | High | JWT and refresh token stored in `localStorage` | **Open** *(architectural)* | Moving refresh tokens to `HttpOnly`, `Secure`, `SameSite=Strict` cookies requires cross-service Auth API cookie support + CORS credentials alignment across portals. |
| **H5** | High | Rich-text HTML (`TinyMCE`, `PageBody`, `MarkupString`) stored-XSS risk | **Partial** *(code sanitized; CSP open)* | `CMSAPI` already sanitizes HTML on write via `Ganss.Xss.HtmlSanitizer` (`NewsletterRepository`, `WidgetFAQRepository`, `Widgets_FixedPagesRepository`). Removed the only `MarkupString` usage in Admin Portal (`MBarChart.razor`, replaced with `RenderFragment` SVG `<text>`). IIS `Content-Security-Policy` response header remains an infrastructure/deployment step. |
| **H6** | High | SignalR notification hub connects without a token | **Closed** *(this pass + client)* | `NewsletterService.StartSignalRAsync` passes `AccessTokenProvider` and resolves the hub from `ApiUrl` (no `localhost` fallback). API `CMSAPI` `AddAuthorizationExtention` reads `access_token` query string for `/hubs/notifications` & `/cms/hubs/notifications`, and `NewsletterNotificationHub` enforces `[Authorize(Roles = "5")]`. |
| **H7** | High | Session timeout math wrong; logout doesn't revoke tokens | **Closed** *(this pass + client)* | `SessionTimeoutService` already uses `(DateTime.UtcNow - lastHeartbeat.ToUniversalTime()).TotalMinutes`. `AuthService.LogoutAsync` now calls `POST auth/api/v2/Auth/Logout` via `SignedClient` before clearing `localStorage`. |
| **H8** | High | `.NET 8` out of support; packages behind | **Open** *(upgrade)* | `EgyMartAdminPortal.csproj` still targets `net8.0` (`8.0.11` packages). Upgrading to `.NET 10` + compatible `Radzen.Blazor` / `Blazor.Bootstrap` / `TinyMCE.Blazor` packages requires dedicated upgrade & UI regression testing. |
| **H9** | High | Admin login uses `SupplierLogin` (`PortalType = 3`) | **Closed** *(already fixed on API)* | API `AccountsRepository.Login` restricts `PortalType == 3` to `UserTypeID IN (3, 4, 5)` (rejecting customers `1` and suppliers `2`). |
| **M1** | Medium | Bearer token sent to any host | **Closed** *(already fixed)* | `JwtAuthorizationMessageHandler.IsApiRequest` attaches `Bearer` token only when scheme + host + port match `ApiUrl`. |
| **M2** | Medium | Parallel token refreshes race each other | **Closed** *(already fixed)* | `JwtAuthorizationMessageHandler` serializes refreshes with `SemaphoreSlim _refreshLock = new(1, 1)`. |
| **M3** | Medium | Redirect check bypassable; pages render before it runs | **Closed** *(this pass)* | `App.razor` uses `Navigation.ToBaseRelativePath(...)` (`StartsWith("login")`) and gates `<Router>` behind `_authChecked && (_isAuthenticated || IsLoginRoute())`, so protected pages do not render or fire API calls prior to auth validation. |
| **M4** | Medium | Expired tokens still count as logged in | **Closed** *(this pass)* | `AuthService.HasValidSessionAsync()` decodes JWT `exp` (`IsTokenExpired`) and runs `TryRefreshTokenAsync()` if expired; otherwise returns `false`. |
| **M5** | Medium | Password reset is a `GET` request | **Closed** *(this pass)* | `UserService.ResetPasswordAsync` changed to `PostAsync`; API `UsersV2Controller.ResetPassword` already supports `[HttpPost("ResetPassword")]`. |
| **M6** | Medium | Raw server errors and exception text shown to users | **Closed** *(this pass)* | `UserService`, `StoreService`, `CouponService`, and `NewsletterService` sanitize HTTP errors via `SafeErrorMessageAsync` (generic message for 5xx/unparsed responses) and log via `ILogger`. API `NewsletterController.SendBroadcast` no longer returns `ex.Message` on HTTP 500. |
| **M7** | Medium | Uploads checked only in browser; `ImageService` is a stub | **Closed** *(this pass + API)* | Deleted unused stub `Services/ImageService.cs` and its DI registration. API `NewsletterRepository.SaveAttachmentAsync` validates extension, 30 MB max size, image magic bytes (`UploadSignatures.IsImage`), and PDF magic bytes (`UploadSignatures.IsPdf`). |
| **M8** | Medium | Upload bodies lost on retry; non-JSON bodies crash signing | **Closed** *(already fixed + C2)* | `JwtAuthorizationMessageHandler` buffers (`LoadIntoBufferAsync`) and clones content/headers before retry; `SignatureHandler` removed. |
| **M9** | Medium | `.gitignore` misses credential, certificate, and backup files; check history | **Closed** *(verified)* | `.gitignore` covers `.env*`, `*.publishsettings`, `*.pfx`, `*.pem`, `*.key`, `*.bak`, `*.sql`, `*.mdf`, `*.log`, `*.zip`, `**/web.config`. Git history check (`git log --all --full-history`) showed `appsettings.json` (`ApiUrl` only, 7 lines) and `publish/web.config` were removed in `89b0e7a`; no `.publishsettings` or secret keys were found in history. |
| **M10** | Medium | `wwwroot/appsettings.json` is public in WASM | **Closed** *(already fixed)* | Contains only `{"ApiUrl": "http://localhost:70"}` (no secrets). |
| **M11** | Medium | `lastVisitedUrl` may allow open redirect after login | **Closed** *(this pass + prior)* | `AuthService.LogoutAsync` stores relative `ToBaseRelativePath` instead of full URI; `Login.razor` validates `IsSafeLocalUrl` before navigating. |
| **L1** | Low | ~30 `Console.WriteLine` error logs & commented debug line | **Closed** *(this pass)* | Replaced all `Console.WriteLine` / `Console.Error.WriteLine` calls across services and Razor components with `ILogger` / `ILoggerFactory`; removed `SignatureHandler.cs` and `Dashboard.razor` debug block. Zero `Console.Write*` / `Console.Error*` calls remain. |
| **L2** | Low | `ApiUrl` not required to be HTTPS; `PlainClient` audit | **Closed** *(this pass)* | `Program.cs` validates `ApiUrl` as an absolute URI and enforces `https://` when `!builder.HostEnvironment.IsDevelopment()`. Audited `PlainClient` callers: only `AuthService.LoginAsync` and `AuthService.TryRefreshTokenAsync` use `PlainClient`. |
| **L3** | Low | Three UI libraries loaded; old `Chart.js` 3.7.1 | **Open** *(UI refactor)* | `Blazor.Bootstrap`, `Radzen.Blazor`, and `Chart.js` `3.7.1` are still referenced across multiple pages/components; consolidating UI libraries requires dedicated frontend refactoring. |
| **L4** | Low | Duplicate `SubscriptionService` / `SubscribtionService` | **Closed** *(this pass)* | Deleted unused `Services/SubscribtionService.cs` and `Models/Subscribtion.cs`. Only `SubscriptionService` (`ads/api/jpt/v2/Ads/ManageSubscriptions/*`) remains. |

## Remaining Open / Deferred Items

1. **H4 — Move tokens out of `localStorage` into `HttpOnly` cookies**: Requires coordinated backend Auth + API Gateway + StoreFront/Supplier/Admin portal cookie-auth redesign.
2. **H5 (partial) — `Content-Security-Policy` header**: Backend `HtmlSanitizer` and client `MarkupString` removal are complete; IIS response header `Content-Security-Policy` should be configured and tested in IIS alongside Blazor WASM and CDN assets (`index.html`).
3. **H8 — Upgrade `.NET 8` to `.NET 10`**: Requires upgrading target framework and verifying `Radzen.Blazor`, `Blazor.Bootstrap`, and `TinyMCE.Blazor` compatibility.
4. **L3 — Consolidate UI libraries (`Blazor.Bootstrap` / `Radzen.Blazor` / `Chart.js` 3.7.1)**: Requires UI component refactoring across pages.
